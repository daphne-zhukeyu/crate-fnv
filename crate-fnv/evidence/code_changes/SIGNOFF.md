# Sign-off sheet

One line per finding in CODE_CHANGES.md. Reviewer fills in the box, a
classification (`ghost-only` / `behaviour-preserving` / `behaviour-change` / `trusted-ok` /
`REJECT`) and initials. The report counts only lines with `[x]`.
